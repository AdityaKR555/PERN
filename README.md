
# Contact Shontact 📇

A simple mini project built to learn PostgreSQL integration with Node.js and Express.js.

## ✨ Features
- Create, view, update, and delete contacts (CRUD)
- Dark mode with smooth transitions
- Responsive UI

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL

## 🎯 Purpose
A small learning project to practice PostgreSQL with Node.js and Express.js.
